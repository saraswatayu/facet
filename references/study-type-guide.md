# Study Type Guide

Match the user's research question to the right study type.

## Keyword Matching

| Keywords in question | Study type | What it tests |
|---------------------|-----------|--------------|
| price, charge, cost, tier, plan, subscription, pay, afford | `pricing` | Willingness to pay, tier preference, price sensitivity |
| copy, messaging, headline, positioning, tagline, slogan, brand voice | `copy` | Message clarity, trust, motivation, which variant resonates |
| feature, should we build, worth adding, capability, functionality | `features` | Feature importance, excitement, willingness-to-pay delta |
| onboarding, activation, first-time, signup, getting started, tutorial | `onboarding` | Completion funnel, time-to-value, psychological ownership |
| retain, churn, keep users, engagement, loyalty, cancel, renew | `retention` | Satisfaction arc, churn triggers, honest vs passive retention |
| *(no clear match)* | `custom` | Natural decision-making, no framework injection |

## When to Use Each

**Pricing** — "Should we charge $X or $Y?" "Freemium or paid?" "Annual vs monthly?"
Personas get prospect theory, mental accounting, loss aversion frameworks.

**Copy** — "Which tagline works?" "Does this landing page convert?" "Trust or urgency?"
Personas get ELM (central/peripheral routes), framing effects.

**Features** — "Should we build X?" "What do users care about most?"
Personas get Kano model (must-be/performance/attractive/indifferent).

**Onboarding** — "Which signup flow is better?" "How do we activate users?"
Personas get endowment/IKEA effect, Fogg B=MAP, status quo bias.

**Retention** — "Why do users churn?" "Which retention strategy works?"
Personas get hedonic adaptation, sunk cost, peak-end rule.

**Custom** — "Something that doesn't fit the above." No framework injection.
Personas use whatever decision-making is natural to their background.

## Multi-Study Configurations

Some questions need multiple studies. Common combos:
- "Should we launch this?" → concept reactions + pricing + features (3 studies)
- "How should we price AND onboard?" → pricing + onboarding (2 studies)
- "Full product audit" → onboarding + features + pricing + retention (4 studies)

See study-templates/ for pre-built multi-study configurations.
